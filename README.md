# Interactive-gearbox-diagram-template

A **single-file HTML template** for presenting an **interactive gearbox diagram** in the browser.

This repository is intentionally minimal: it currently contains **one HTML file** — `lift_gearbox_diagram.html` — and GitHub reports the project as **HTML (100%)** with a **single commit**. :contentReference[oaicite:0]{index=0}

---

## What this repo is

The goal of this template is to give you a **drop-in starting point** for an interactive “technical diagram” experience (click/hover to identify components, highlight parts, show labels/callouts, etc.) centered around a **lift/elevator gearbox** diagram (as implied by the filename).
